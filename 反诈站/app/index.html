骗 局 怎 么 运 转

名字一直在换，走的路数没变。

刷单、投资、客服、公检法，剧本各不相同，但都走这五步。认出第三步，就基本安全了。

0 1
接近

陌生来电、短信、群聊、快递里的小卡片。他先让你看见他。

0 2
建立信任

报出你的姓名、尾号和订单号。他知道你的事，不代表他就是真的，但他要你这么想。

0 3
制造紧迫

"今晚十二点失效""两小时后冻结""再不处理就移交"。不管换什么说法，他一定会催。

0 4
隔离

"别挂电话""别告诉家里人""这是保密案件"。说来说去就一个意思：别去问别人。

0 5
取钱

转账、念验证码、开屏幕共享、寄现金。这一步一旦做完，钱就回不来了。

第三和第四步往往是同时来的：一边催你，一边让你别问别人。人被这么夹着，很容易乱。
挡的办法很土，先挂掉，再找个真人问一句。
