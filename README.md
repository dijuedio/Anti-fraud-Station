# 两个项目

这个仓库里装了两个自己写的小东西：一个是手机里的文字模拟器，一个是反诈体验站。
两个都是 Python 单文件后端加一堆前端页面，不装框架，双击就能跑。

## 第一年（`第一年/`）

一个网页上的文字模拟器，做成一部手机的样子。

你二十二岁，刚毕业，来到一座陌生城市，兜里八千块，要撑过九十天。这一年里发生的事全在手机里：
微信、短信、来电、备忘录、钱包。谁跟你说了什么，你得当场回一句。

剧本写在数据里，台词由模型即兴生成。没配模型也能玩，走预置台词。

怎么跑：

```
cd 第一年
双击 启动.bat
```

它会自己开浏览器，地址 <http://127.0.0.1:8010>。命令行也行：`python server.py`，默认 8000 端口。

第一次打开先注册，账号存在本机的 `data/users.db`，密码加盐哈希后存，不是明文。

## 反诈站（`反诈站/`）

给刚毕业、刚入学的人做的一组反诈体验页面，六个入口：

认一认（判断话术）、学一学（话术解剖）、扫一条（扫一眼识破）、演一次（当一回被骗的人）、骗一次（反过来试试骗人的话术）、首页。

剧本同样写在 json 里，接上模型能实时对话，没有模型走预置台词。

怎么跑：

```
cd 反诈站
双击 启动.bat
```

地址 <http://127.0.0.1:8020>。

## 说明

两个项目的 `.env` 都没进仓库，里面放的是模型 key。换机器跑的时候自己补一份，变量名看代码里 `os.environ.get` 那几行。

`第一年/_archive/` 是开发过程的补丁脚本和旧版本，留着当记录，不进仓库。
