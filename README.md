# 两个项目

这个仓库里装了两个自己写的小东西：一个是手机里的文字模拟器，一个是反诈体验站。
两个都是 Python 单文件后端加一堆前端页面，不装框架，双击就能跑。

## 第一年（`第一年/`）

一个网页上的文字模拟器，做成一部手机的样子。

你二十二岁，刚毕业，来到一座陌生城市，兜里八千块，要撑过九十天。这一年里发生的事全在手机里：
微信、短信、来电、备忘录、钱包。谁跟你说了什么，你得当场回一句。

剧本写在数据里，台词由模型即兴生成。没配模型也能玩，走预置台词。

怎么跑：

```
cd 第一年
双击 启动.bat
```

它会自己开浏览器，地址 <http://127.0.0.1:8010>。命令行也行：`python server.py`，默认 8000 端口。

第一次打开先注册，账号存在本机的 `data/users.db`，密码加盐哈希后存，不是明文。

## 反诈站（`反诈站/`）

给刚毕业、刚入学的人做的一组反诈页面。首页是一条从头看到尾的线：

现状 → 骗局怎么运转（五步）→ 十种高发 → 按年龄看 → 常用手段 → 话术解剖 → 十个凡是 → 该怎么做。

**按年龄看**把人分成四组：学生 15–22、刚工作 23–30、中年 31–50、老人 55+。每组五条最容易
中招的剧本，只写"怎么开始、关键在哪一步"，四张卡长短对齐。谁看哪一张，一眼就找得到。

**常用手段**是十二条跨剧本通用的手法：报出你的信息、给你一个倒计时、让你别问人、让你装个 App、
让你开几个权限、只要六个数字、让你共享屏幕、先返你一点、让你绕开平台、让你看见别人都在赚、
换个脸换个声音、让你把现金黄金交出去。每条配一句能当场拦住他的话。

往下还有五个能动手的入口：认一认（判断话术）、学一学（话术解剖）、扫一条（贴一条消息看看）、
演一次（当一回被骗的人）、骗一次（反过来试试骗人的话术）。

剧本同样写在 json 里，接上模型能实时对话，没有模型走预置台词。

怎么跑：

```
cd 反诈站
双击 启动.bat
```

地址 <http://127.0.0.1:8020>。

## 说明

两个项目的 `.env` 都没进仓库，里面放的是模型 key，位置是各自目录下面（`第一年/.env`、`反诈站/.env`）。换机器跑的时候自己补一份，变量名看代码里 `os.environ.get` 那几行。

`第一年/_archive/` 是开发过程的补丁脚本和旧版本，留着当记录，不进仓库。

两个项目都只用 Python 标准库，`requirements.txt` 是空的，留着是给云端构建一个明确的东西可装。
